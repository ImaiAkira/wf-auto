# 页面判据全局唯一，场景按需引用与覆盖

## 背景

"这个画面算哪个页面"是一条判据。它可以全局共享一份，也可以每个场景自带一套。DSH 的审计反复证明：判据抄两份就会各自漂 —— 两次「恒绿断言」（复制的期望值其实指向另一个常量）和「漏掉的第四处硬编码」都是这么来的。

## 决定

页面判据**全局唯一一份**，放在共享层；场景配置**引用**它，只有在确有差异时才声明**覆盖**。

## 考虑过的选项

- **(a) 每场景自带一套判据** —— 领主战类 39 个成员会把同一套判据复制 39 份；任何一处的修补都不会传播到其余 38 处。
- **(b) 本决定。**

## 后果

- 一旦引入"覆盖"，就必须能回答"这个场景覆盖了哪些判据、为什么"。否则**覆盖会成为新的隐形分叉点** —— 这正是要消灭的东西。
- 覆盖应当是**例外**而非默认：校验器应当报告"某场景覆盖了全局判据"作为提示，让人有意识地接受它。
